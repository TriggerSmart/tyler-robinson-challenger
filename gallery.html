Challenger Image Gallery

Click any thumbnail to open a full-screen viewer. Mouse wheel / pinch zooms; drag pans; double-click zooms. The viewer allows zoom well beyond 1:1 for pixel-level inspection. All 24 images uploaded for this stream are bundled inside this website as byte-for-byte original files under assets/images/originals/. The thumbnails are separate optimized previews. The tint/glass quick set reuses those same bundled originals without creating altered copies.

OpenSeadragon viewer

Uses OpenSeadragon 6.1.1 (BSD-3-Clause) in simple-image mode with deep zoom and pan. If the OpenSeadragon CDN is unavailable, the page automatically falls back to the bundled local pan/zoom viewer; the evidence images themselves are always local website assets.

Controls

Use + / −, reset, rotate, fullscreen, previous/next, mouse wheel, pinch, or keyboard arrows. ESC closes the viewer.
