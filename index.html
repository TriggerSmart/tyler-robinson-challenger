The Challenger

This is the production source console for the finalized 6,500-spoken-word Challenger livestream. Its sections and resources follow the script in the same order. Spoken narration is kept in the separate script file; this page contains the items you open on screen.

Flow lock: resources are intentionally repeated whenever the script returns to them. Video links are deep-linked to the timestamp used in the stream. Uploaded evidence/reference images are bundled with the website and live on the separate zoomable gallery page.
